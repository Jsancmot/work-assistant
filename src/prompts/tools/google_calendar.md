## Google Calendar

Use Google Calendar tools when Julián asks about his schedule, meetings, or wants to create or modify events.

### Which tool to use
- **List upcoming events** → `calendar_list_events` with a time range
- **Create an event** → `calendar_create_event` with title, date/time, and optional description
- **Update an event** → `calendar_update_event` with the event ID and the fields to change
- **Delete an event** → `calendar_delete_event` with the event ID

### Notes
- Before creating or modifying an event, always confirm the date and time if not clearly specified.
- When Julián says "tomorrow" or "next week", resolve the exact date before calling the tool.
